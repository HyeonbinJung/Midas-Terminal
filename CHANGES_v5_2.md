# Midas Terminal v5.2

- Added F4 **SCREENER** powered by yfinance / Yahoo Finance.
- Added selectable classification filters for market cap, sector, volatility, beta, style, growth, profitability, leverage, cash flow, dividend, momentum, liquidity, and cyclicality.
- Screener returns up to five exact matches from a curated liquid U.S. equity universe and shows the live metrics used to classify each result.
- Added one-click **OPEN** from screener results into the F1 market snapshot.
- Shifted SYSTEM to F5.
- Reworked the UI from navy to a near-black mechanical terminal theme with muted graphite borders and lime status accents.
