SYSTEM / DATA

Terminal Architecture · v5.11

A MARKET DATA

Yahoo Finance / yfinance supplies price and financial data. Market, research and peer results use TTL caches plus single-flight locks so concurrent users reuse the same upstream request.

B FILINGS

SEC EDGAR enrichment uses a shared cache and a global request limiter. Company background is populated from annual filings and proxy materials when available.

C OUTPUT

DOCX exports use UUID filenames, per-ticker locks and a bounded worker queue. Files are deleted after delivery. Highlights, catalysts and risk factors are populated automatically from public data. Research exports can be generated in English or translated to Korean with googletrans; recommendation, thesis and DCF remain analyst-owned.
